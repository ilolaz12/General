\subsection*{Maths in Urban Lighting Projects}
In a vocational school project on urban lighting, I developed a formula to translate lux into volts and vice versa. The formula is given by:
\begin{equation}
    \text{Lux} = \frac{V}{R} \cdot \eta,
\end{equation}
where \(V\) represents voltage, \(R\) is resistance, and \(\eta\) is the efficiency factor of the lighting system. This helped the school monitor energy consumption and optimize lighting efficiency.

\subsection*{Basic Computer System Components}
Here is a list of basic computer system components often used in modern computing systems:
\begin{itemize}
    \item \textbf{Central Processing Unit (CPU):} Handles all processing and executes instructions.
    \item \textbf{Memory (RAM):} Temporary storage for running processes and applications.
    \item \textbf{Storage Devices:} Includes SSDs and HDDs for long-term data storage.
    \item \textbf{Motherboard:} The main circuit board connecting all components.
    \item \textbf{Power Supply Unit (PSU):} Provides electrical power to the system.
    \item \textbf{Graphics Processing Unit (GPU):} Specialized hardware for rendering images and video.
    \item \textbf{Input/Output Devices:} Includes peripherals like keyboards, mice, and monitors.
\end{itemize}
